# P7 待裁决清单·第二轮（2026-11-21）

第一轮 19 条已全部落地，见 `temp/p7-decisions.md`。以下是**仍未定、且会影响实现口径**的 8 条；在每条「裁决：」后直接写答案，或回消息 `P7-2-X1=…` 即可。

### P7-2-X1 记者「独家新闻」的幻影有没有「主动销毁」与「受击绑定」

- 现象：原文只写「召唤牵制幻影（限三次）」「召唤救援幻影（限一次）」，没写幻影怎么消失。当前只做到召唤落地 + 两分支各自每局限次，**没有消失规则**，所以「牵制」的实际强度被高估。
- 默认（已落地）：幻影不设消失规则，分支用尽后不能再召，已召出的幻影永久留存。
- 裁决：消失就是死亡（由于每回合血量-1，所以正常情况下会自然死亡）。

### P7-2-X2 勘探员「陨石磁铁」的攻击力 -1 持续多久

- 现象：原文「对目标造成伤害并使其攻击力 -1」，未写时长（永久 / 一回合 / 到下个己方回合结束）。
- 默认（已落地）：到下个己方回合结束（`untilNextOwnTurnEnd`）。
- 裁决：永久

### P7-2-X3 木偶师「路易」是否也由非伤害扣血触发

- 现象：原文「本体血量将要减少时」。当前只在攻击/技能伤害（`beforeDamage`）与救援扣血前触发，不覆盖标记扣血（`drainMarks`）、延迟伤害、道具或技能直接改 hp。
- 默认（已落地）：只认伤害与救援两种来源。
- 裁决：覆盖标记扣血、延迟伤害、道具，但不覆盖直接改hp。总之就是尽可能的让扣的血量变少。

### P7-2-X4 心理学家「应激」是否严格按「任何时候」而非「受击后」

- 现象：原文「任何时候，血量小于 4，则回复两点血量，限两次」。当前是受击后触发（`trigger:"damaged"` + `hpLt:4`），因此「因技能扣血/标记/延迟伤害掉到 4 以下」不会回血。
- 默认（已落地）：维持受击近似（第一轮已判「默认」）。
- 裁决：技能扣血/标记/延迟伤害等也要触发。

### P7-2-X5 魔术棒本体「受到的伤害减半」要不要实装

- 现象：原文「使用魔术棒后，下次受到的伤害减半」。当前只有魔术师本人的「至多 1 点」（`wandCap1`），通用的「减半」没做——`useItem` 路径拿不到受击者上下文。
- 可行做法：(a) 改道具数据结构，让魔术棒显式选择一个己方角色挂「下次受伤减半」；(b) 不实装。
- 默认（已落地）：(b)。
- 裁决：（a）

### P7-2-X6 舞女「二重奏」的八音盒本体要不要实装

- 现象：`bayinhe` 在 `data/effects.json` 里仍是 `custom:modalChoice`（使用后抉择加攻/减攻，攻击或被攻击后删增益），引擎没有对应 op；舞女的「增益不消失」flag 因而没有消费方。属引擎表达力问题，不是语义歧义。
- 可行做法：(a) 新增抉择式道具 op + 攻击/受击后自清 flag，一次把八音盒做成 full；(b) 维持现状。
- 默认（已落地）：(b)。
- 裁决：（a）

### P7-2-X7 安抚物「钢铁护肘」映射到「护腕」是否可接受

- 现象：道具表没有「钢铁护肘」，第一轮默认映射到既有道具「护腕」（`huwan`，与佣兵「钢铁冲刺」给的是同一件道具的不同叫法）。若原文里是两件不同效果的道具，该映射需要拆开。
- 默认（已落地）：映射到 `huwan`，不新增第 16 件道具。
- 裁决：默认
