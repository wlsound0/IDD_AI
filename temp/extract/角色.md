# 角色结构化摘要

来源：`temp/extract/raw/角色.txt`（5576 字符，UTF-8）。机器可读版本见 `temp/data/characters.json`。

## 阅读说明

- **类型**：原文 `品质：` 字段，映射为 普通→`normal`、史诗→`epic`、限定→`limited`、传说→`legend`（原文未出现传说）。原文无品质标注的记 `未标注`。
- **攻击 / 血量**：取自 `面板：X/Y`，按 X=攻击、Y=血量 解读（原文未明写顺序，见"歧义与待确认"1）。
- **花费**：`花费：Nk`，JSON 结构无对应字段，故仅在本表保留。
- **技能 text**：JSON 中逐字保留原行（含技能名、括号内的 CD/充能/耐久标注与全部标点），多行条目（邮差"邮件"的信件子项）以 `\n` 原样拼接；仅去掉行首缩进与行尾空格。
- **技能类型判定规则**（原文未给字段，按标注推断，属约定）：
  1. 明写`战吼` → `battlecry`；
  2. 明写`CD：N` → `cooldown`（CD 值入 `cooldown`）；
  3. 明写`充能` → `charge`；
  4. 带`耐久度`且可主动使用 → `active`（耐久值入 `durability`）；
  5. `限一次/限两次`且由玩家主动选择目标或使用 → `active`；
  6. 事件触发（受伤时、回合结束时、攻击后、死亡后、进入濒死时等）→ `passive`；
  7. 纯关键词特质（庄园老友、救援、自我救援）→ `passive`；
  8. 无任何机制文本 → `unknown`（仅"期待"一处）。

## 歧义与待确认

1. **"面板：X/Y"未标注顺序**。本表统一按 X=攻击、Y=血量 解读（依据出现"0/4""4/1"等极端值及"攻击力/血量"的常规写法），但原文从未说明，需确认。
2. **"花费：Nk"无处安放**。JSON 结构无卡牌费用字段，本表保留、JSON 未存；若后续需要，应扩展 schema（而不是塞进技能 `cost`）。技能 `cost` 全部为 null：原文的"消耗充能/消耗耐久"都是技能内子选项，且与 `cooldown`、`durability` 语义重叠。
3. **关键词特质没有名字也没有描述**。`庄园老友。`（幸运儿/律师/医生/园丁）、`救援。`（守墓人/大副/空军/击球手/杂技演员/木偶师/记者/前锋）、`自我救援。` 只有关键词。现已按关键词命名收录为 `passive`，但它们是否是"技能"、是否需要单独的全局关键词表，未定。
4. **召唤物/附属单位被排除**。记者的"牵制幻影""救援幻影"、昆虫学者的"虫群"都带独立 `面板：0/2` 与技能描述，但不带 `品质`。本次未计入 43 个角色，也未把其描述并入对应技能 text，需确认是否应作为独立单位数据（这对记者与昆虫学者影响最大）。
5. **玛恩纳（联动）/ 雷德（联动）名字带"（联动）"**。"联动"是版本身份标注还是名字的一部分？JSON `name` 保留原文全称，若用作显示名/键名需拆分。
6. **"传说"稀有度不存在**。文档只出现普通/史诗/限定三档，schema 中的 `legend` 与 `unknown` 在本数据中必为空；需确认是否有未写入文档的传说卡。
7. **未照耀的荣光有两个 CD**（初始 CD 1、之后 CD 2），单一 `cooldown` 字段无法表达，已置 null、原文留在 text 中。
8. **充能写法三套并存**：`1/5`（先知、祭司 2/3、勘探员 1/3、小女孩 1/3、咒术师 0/5）、`1/1`（入殓师）、只写"每回合充能一次"无分数（拉拉队员、激励）。`X/Y` 是"当前/上限"还是"每次获得/上限"未定义；先知的"每两回合充能一次"与 `1/5` 的关系（两回合才 +1 则 5 点需 10 回合）也未说明。
9. **"限一次/限两次"的作用域不清**：是每局一次、每张卡一次，还是每次上场一次？如盲女"回声定位"、大副"失乐园"、雷德"整合运动"（死亡后仍限一次）。
10. **CD：0 的语义**。 psychologists 移情、病患钩爪逃生、记者独家新闻、园丁巧手匠心、牛仔套索技艺都是 CD 0，既可理解为"无冷却、可反复用"，也可理解为"用后当回合不可用"，与"限 N 次"叠加后仍不明确。
11. **同类特质在不同角色上文本不一致**：`羸弱` 有"自身反伤造成的伤害减一"（机械师、盲女）与"反伤造成的伤害-1"（祭司）两种写法，是否同一效果、是否只对自身反伤生效不清；`庄园老友` 四条完全无描述。
12. **野人的救援自相矛盾**："救援只扣一血，但必扣本体"与"（被封技能时）优先扣除临时血量"冲突——必扣本体 vs 优先扣临时血量，需定裁决顺序。
13. **佣兵"坚强"的标记上限歧义**："自动尽可能多地减少标记（最多3个）"是每回合最多消 3 个，还是标记总量上限 3 个，未说明；且"减少标记→等量扣血"使该特质实际是延迟伤害。
14. **飞行家"救援；救援时…"与"特发性震颤"叠加**：特发性震颤给的"自我救援"是否也受"消耗飞行器免伤"约束不明。
